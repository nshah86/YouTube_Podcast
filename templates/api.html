API documentation

Generate an API token from your account, then call the API with an Authorization: Bearer <token> header.

Authentication

curl -H "Authorization: Bearer YOUR_TOKEN" https://YOUR-DOMAIN/api/transcripts

Tokens are per-user and revocable from your account. Keep them secret — they inherit your plan's quotas.

Rate limits

Per-endpoint rate limiting applies (burst protection). Exceeding it returns 429 — back off and retry.

API request quotas

Requests are counted per calendar month, per user:

  • Free: 20 / month
  • Plus: 2,000 / month
  • Pro: 50,000 / month
  • Enterprise: 50,000 / month

Exceeding your quota returns 429 with an upgrade_url. AI endpoints (/api/summarize, /api/podcast, /api/clips) additionally consume AI tokens from your plan's token quota (10 per call).

Quota headers

Every API response carries:

X-Quota-Limit: 2000
X-Quota-Remaining: 1843
X-Quota-Plan: plus

POST /api/transcripts Free+

Fetch transcripts for up to 50 video IDs.

curl -X POST https://YOUR-DOMAIN/api/transcripts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ids":["dQw4w9WgXcQ"]}'

POST /api/summarize Plus+

AI summary (title + 400–600 words) of a video. Consumes 10 AI tokens.

curl -X POST https://YOUR-DOMAIN/api/summarize \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'

POST /api/podcast Plus+

Two-host conversation script + MP3 for a video. Optional voice: female (default), male, mixed. Consumes 10 AI tokens. Returns audio_url for the MP3 download.

curl -X POST https://YOUR-DOMAIN/api/podcast \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ","voice":"mixed"}'

POST /api/clips Plus+

Top 3 shareable short-clip moments (timestamps + titles) for a video.

curl -X POST https://YOUR-DOMAIN/api/clips \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'

POST /api/channels Plus+

Channel info lookup (requires YouTube Data API key configuration).

MCP server

Use VideoTranscript Pro from Claude Desktop or any MCP client: run mcp_server.py (see DEPLOY.md) with VTP_API_TOKEN set. Tools: get_transcript, summarize_video, generate_podcast_episode, find_clip_moments — all plan-gated and quota-counted.
